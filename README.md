# Power BI Data Analysis & Dashboard

## Overview

This project demonstrates the use of Microsoft Power BI to transform
data into an interactive and meaningful business dashboard.

## Key Features

- Data cleaning and transformation
- Data modelling
- KPI analysis
- Interactive dashboards
- Charts and visualizations
- Business insights
- Report filtering and drill-down analysis

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis

## Project Outcome

The dashboard provides a clear visual overview of key performance
indicators and helps users understand trends and patterns in the data.
